# Crop icons

These PNG files are game art from Palia. They belong to Singularity 6 / Daybreak Game Company and are used here for reference in a free fan tool. They are not covered by any license this project grants for its own code, and nothing here claims ownership of them.

`sources.json` records the file each icon came from (the Palia wiki), its page, and the date they were fetched.

To refresh them, download the 128px version of each crop's icon from the wiki and save it as `<crop id>.png`, matching the ids in `src/data/crops.json`.

The app treats icons as optional: delete the PNG files and every crop falls back to a colored tile with its short label.
